Garnet

The Discord bot engine.

Garnet is a Discord bot engine you run yourself. Download it, add your bot token, and switch features on or off in one config file. Tickets, role panels, logging, welcomer, moderation and embeds are included.

Download main.jar Join our Discord

Version alpha_v1.0.0 · Requires Java 21 or newer

Run it

Download the file, then start it from a terminal in the same folder.

java -jar main.jar
