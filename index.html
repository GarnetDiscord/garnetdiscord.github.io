What's included

Every feature can be turned on or off in your config file.

  • Tickets

    Let members open private support channels, with limits and delete confirmation.

  • Role panels

    Members pick their own roles from a panel you build right inside Discord.

  • Logging

    Keep a record of joins, edits, deletions and other server activity.

  • Welcomer

    Greet new members with a message of your own.

  • Moderation

    Keep your server in order with the usual tools for dealing with rule-breakers.

  • Embeds

    Send polished, formatted messages and announcements.

Install in three steps

  1. Download and check Java

    Download main.jar into its own folder. Garnet needs Java 21 or newer, so check your version first.

    java -version

    The version it prints should be 21 or higher.

  2. Run it once

    Open a terminal in the same folder and start the bot. It will create config.yaml and a few other files, then you can stop it.

    java -jar main.jar

    On a hosting service, you can use this command or set main.jar as the startup file.

  3. Add your token and start again

    Open config.yaml and paste in your Discord bot token and your bot's name. Other optional features are in the same file. Then run the command from step 2 again.

    token: "YOUR_BOT_TOKEN"
bot-name: "My Bot"

    Keep your token private. Anyone who has it can control your bot.
